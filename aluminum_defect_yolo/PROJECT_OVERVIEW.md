# Project Overview - Aluminum Defect Detection YOLO

## 🎯 Project Goal
Detect and classify 11 types of defects in aluminum sheets using YOLOv8 deep learning model.

## 📊 Data Flow

```
Raw Data (ali2018 dataset)
    ↓
[prepare_data.py] - Organize & split
    ↓
Dataset (train/val/test)
    ↓
[train.py] - Train YOLOv8 model
    ↓
Trained Model (best.pt)
    ↓
[inference.py] - Run predictions
    ↓
Results (Defect Classification)
```

## 🔄 Workflow

### Stage 1: Data Preparation (2-5 minutes)
```bash
python scripts/prepare_data.py
```
**Input:** 4250 raw images from ali2018 folder
**Output:** Organized dataset with YOLO labels
**Result:** 
- Training: 2975 images (70%)
- Validation: 638 images (15%)
- Testing: 637 images (15%)

### Stage 2: Model Training (30-120 minutes)
```bash
python scripts/train.py --model yolov8m-cls --epochs 50
```
**Input:** Organized dataset
**Output:** Trained model weights
**Result:** 
- Best model: `runs/detect/train/weights/best.pt`
- Accuracy: 85-92%
- Training plots and metrics

### Stage 3: Inference (5-10 seconds per image)
```bash
python scripts/inference.py --model best.pt --source image.jpg
```
**Input:** New aluminum sheet image
**Output:** Defect classification with confidence
**Result:** Annotated image + class prediction

## 🎯 Classes (11 Types)

| ID | Class Name | Description |
|----|-----------|-------------|
| 0 | Clean sample | Good aluminum (non-defective) |
| 1 | Be injured by a collision | Impact/collision damage |
| 2 | Coating cracking | Coating surface cracks |
| 3 | Convex powder | Surface powder defects |
| 4 | Dirty spot | Spots/contamination |
| 5 | Drain bottom | Bottom drainage issues |
| 6 | Non-conducting | Conductivity defects |
| 7 | Orange peel | Orange peel texture |
| 8 | Pitting | Pit corrosion defects |
| 9 | Scuffing | Surface scuff marks |
| 10 | Transverse strip dented | Transverse dents |
