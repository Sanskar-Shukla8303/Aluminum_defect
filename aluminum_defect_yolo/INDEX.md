## 🔧 Scripts Guide

### 1. **prepare_data.py** - Data Preparation
```bash
python scripts/prepare_data.py
```
**What it does:**
- Organizes 4250+ images from ali2018 dataset
- Creates YOLO format labels
- Splits into train/val/test (70/15/15)
- Generates dataset.yaml

**Output:**
```
data/
├── images/ (organized by split)
├── labels/ (YOLO format)
└── dataset.yaml ✓
```

**When to use:** First step - once to prepare data

---

### 2. **train.py** - Model Training
```bash
python scripts/train.py --model yolov8m-cls --epochs 50
```
**What it does:**
- Downloads YOLOv8 weights
- Trains on your dataset
- Saves best model as best.pt
- Creates results visualization

**Output:**
```
runs/detect/train/
├── weights/best.pt ← Use this for predictions
├── results.csv (metrics)
├── results.png (plots)
└── confusion_matrix.png
```

**When to use:** After data preparation is complete

**Common options:**
```bash
--model yolov8n-cls    # Nano (fastest)
--model yolov8m-cls    # Medium (recommended)
--model yolov8l-cls    # Large (most accurate)
--epochs 50            # Number of epochs
--batch 32             # Batch size
--imgsz 640            # Image size
```

---

### 3. **inference.py** - Make Predictions
```bash
python scripts/inference.py --model best.pt --source image.jpg
```
**What it does:**
- Runs predictions on images/videos/folders
- Shows predicted class and confidence
- Saves annotated images

**Output:**
```
predicted_image.jpg (with class label)
Console: ClassName: 92% confidence
```

**When to use:** After training complete

**Common options:**
```bash
--source "image.jpg"      # Single image
--source "folder/"        # All images in folder
--source "video.mp4"      # Video file
--conf 0.5                # Confidence threshold (0-1)
--evaluate                # Show statistics
```

---

### 4. **evaluate.py** - Model Evaluation
```bash
python scripts/evaluate.py --model best.pt --data dataset.yaml
```
**What it does:**
- Validates model on test set
- Calculates metrics (accuracy, precision, recall, F1)
- Generates evaluation report

**Output:**
```
evaluation_report.json (metrics summary)
```

**When to use:** After training to check model quality

---

### 5. **utils.py** - Utility Functions
Helper functions for:
- Image analysis
- Dataset statistics
- Training metrics visualization
- Confusion matrix generation

**Import in your code:**
```python
from scripts.utils import ImageAnalyzer, DataAugmentation
```

## 🎯 Typical Workflow

### Day 1: Setup & Preparation (1 hour total)
```bash
# 1. Install (2 min)
pip install -r requirements.txt

# 2. Prepare data (2 min)
python scripts/prepare_data.py

# 3. Check preparation (verify data/ folder created)
dir data/

# 4. Start training (runs for 30-60 min)
python scripts/train.py --epochs 30 --batch 32
```

### Day 2+: Testing & Deployment
```bash
# 1. Test on single image (30 sec)
python scripts/inference.py --model runs/detect/train/weights/best.pt --source image.jpg

# 2. Test on folder (1-2 min)
python scripts/inference.py --model best.pt --source data/images/test/ --evaluate

# 3. Evaluate full model (2-5 min)
python scripts/evaluate.py --model best.pt --data data/dataset.yaml
```

## 💡 Tips & Tricks

### Quick Training
```bash
# Fast 10-epoch test
python scripts/train.py --model yolov8n-cls --epochs 10 --batch 64
```

### GPU Optimization
```bash
# Use maximum batch size for your GPU
--batch 32   # 4-6 GB VRAM
--batch 64   # 8+ GB VRAM
--batch 128  # 16+ GB VRAM
```

### Better Accuracy
```bash
# Increase training time and model size
python scripts/train.py --model yolov8l-cls --epochs 100 --lr0 0.0005
```

### CPU-only Mode
```bash
# Small model, small batch, small image size
python scripts/train.py --model yolov8n-cls --batch 8 --imgsz 416
```
